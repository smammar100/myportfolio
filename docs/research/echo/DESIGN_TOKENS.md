# Echo Template Design Tokens

Source: `https://echo-nextjs-template.vercel.app/` — compiled CSS at `/_next/static/chunks/18b07d5689c3f71b.css`.

## Fonts

- **Primary (body + headings):** Funnel Sans (Google Fonts, via `next/font/google`)
  - CSS variable: `--font-funnel-sans`
  - Body weight: 500 (`--text-weight: 500`)
  - Heading weight: 500 (`--display-weight: 500`)
  - Mono fallback: system mono stack (`--font-mono`)
- **Fallback:** "Funnel Sans Fallback" generated by Next.js

## Spacing
- Base spacing: `.25rem` (Tailwind default — `--spacing: .25rem`)
- Container widths used: `--container-md: 28rem`, `--container-lg: 32rem`

## Radius
- `--radius: .375rem` (6px) is the shadcn baseline
- Larger: `--radius-3xl: 1.5rem`

## Theme behavior
- Default: light mode
- `.dark` class on root toggles to dark
- A theme toggle button is present in the nav
